```
YYYY-MM-DD-HHMM-codex-review-[topic].md
```

- `2026-07-10-1430-codex-review-security.md` - Security review response
- `2026-07-10-1500-codex-review-architecture.md` - Architecture review
- `2026-07-11-0900-codex-review-summary.md` - General summary
