# Plans Index

**Location:** `docs/plans/`

## Overview

This directory contains all implementation plans for the Startup Research Report project. Every non-trivial task requires a documented plan before implementation.

## Plan Status Legend

| Status | Description |
|--------|-------------|
| `DRAFT` | Initial draft, not submitted for review |
| `PENDING_APPROVAL` | Submitted for approval, awaiting response |
| `APPROVED` | Approved, ready for implementation |
| `IN_PROGRESS` | Implementation started |
| `COMPLETED` | Implementation finished and validated |
| `REJECTED` | Rejected, needs revision |
